# Veera Shiva Karthik — Portfolio

Modern, responsive personal portfolio website for **Somisetty Veera Shiva Karthik**.

**Live site:** https://veerashivakarthik.github.io/portfolio/

## Features

- Dark tech-focused design
- Typing animation for roles
- Fully responsive (mobile-friendly)
- Sections: About, Skills, Experience, Projects, Certifications, Education, Contact
- Pure HTML / CSS / JS — no build step required
- Fast loading & SEO-friendly

## Local Preview

Open `index.html` in any browser, or run:

```bash
python -m http.server 8000
```
